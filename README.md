# Testlets

Página de captura da VemMED para solicitar acesso a Testlets, desenvolvida com Astro. O formulário está integrado ao Mautic (ID 16).

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra http://localhost:4321 no navegador.

## Build

```bash
npm run build
```

Para visualizar o build localmente:

```bash
npm run preview
```
